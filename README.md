# deuna_team_SQL-CaFe

Repositorio del equipo Deuna — SQL / CaFe.

## Contenido

| Carpeta | Descripción |
|---------|-------------|
| **FindTech_Proyecto** | Prototipo **FINS** (Deuna): microcréditos, Tu nivel deuna, gamificación (coins, cofres, ruleta) y modo Veci. Stack: React + Vite + TypeScript. |
| **Notebook_Jupyter** | Documentación académica en Jupyter: `documentacion_deuna_fins.ipynb` (reglas de negocio y simulaciones). |
| **Slidedeck_SQL+CaFe** | Material de presentación SQL + CaFe (propuesta y futuros `.pptx` / PDF). |

## Inicio rápido

```bash
cd FindTech_Proyecto
pnpm install
pnpm dev
```

Documentación técnica: `FindTech_Proyecto/documentacion_deuna_fins.ipynb` y `FindTech_Proyecto/propuesta_deuna_ia.md`.
